# 🌐 Bilingual Plan · 英中雙語規劃

> 目標：zh-TW（預設，原型語言）與 en-US 雙語完整支援。雙語是第一天起的內建需求（NFR-6）：所有字串走 i18n key，禁止寫死。

---

## 🧰 Setup · 技術方案

- i18next ＋ react-i18next；locale 檔：`src/i18n/locales/zh-TW.json`、`en-US.json`（兩檔 key 完全對稱）
- 語言解析順序：`Settings.language`（App 內明確設定）→ 系統語言 → 預設 `zh-TW`
- 插值一律用 i18next `{{param}}`；複數用 `_one/_other`（en 需要，zh 不分）
- 日期／時間／時長／百分比：`Intl.DateTimeFormat`／`Intl.NumberFormat`，不得手動串接

## 📏 Formatting Rules · 格式化規則

| 項目 | zh-TW | en-US |
|---|---|---|
| 頁首日期 | `7月13日 · 星期一`（`M月d日 · EEEE`） | `Monday, Jul 13`（`EEEE, MMM d`） |
| 時間 | `14:45`（24h） | `14:45`（24h，與設計一致；12h 為可選未來項） |
| 時長 | `4.7 小時` | `4.7 h` |
| 進度計數 | `2/3` | `2/3` |
| streak | `連續 5 天` | `5-day streak` |

## 🎨 Design Extensions · 設計延伸需求（原型未含，需補設計）

1. **語言切換 UI**：設定分頁「語言 / Language」列（zh-TW / English 二選一），沿用設定卡樣式——**已定案**，規格見 [DESIGN-ADDENDUM.md](./DESIGN-ADDENDUM.md) §C
2. **類別徽章英文化**：漢字徽章（工／眠／食／動／閒／行／他）在 en-US 改用 Latin 首字母（W / S / M / E / L / C / O）或改用共用 icon——建議 icon 方案（兩語一致、無在地化成本），Phase 1 拍板
3. **字體策略**：zh-TW＝M PLUS Rounded 1c 優先；en-US＝Karla 優先（同一家族堆疊，只換順序）
4. **佈局寬容**：en 文字平均長 1.3–1.6 倍，卡片/按鈕不得固定寬；以 en-US 版走查溢出
